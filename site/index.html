Capabilities

Built for multi-feature throughput

Everything needed to coordinate a team of coding agents without losing visibility or control.

One Leader drives dev and review

The Leader opens cards, dispatches workers, watches each one finish, verifies the deliverable and organizes review. Your attention returns to what you want.

A board you can read at a glance

One board per project. Each card carries its executor slot and a live status light; click a slot to drill into that agent's session and keep talking.

Behavior lives in two files

LEADER.md holds the orchestration rules, SLOTS.md gives each worker role its own rules. Editing a file changes behavior live — no session restart.

Many projects, one Leader each

The project tree lists the workers each Leader spawned. Swap in a new Leader and the existing workers plus undelivered reports move over seamlessly.

Read back without waking

read_worker_session reads a worker's session log directly — every turn, every tool call, why anything failed — without waking it or triggering a model call.

Quiet workers get flagged

When a dispatched turn produces no report for 15 minutes, a patrol notice arrives with the session id, its card and a copy-pasteable read-back call.

FAQ

Is this DeepSeek's Super-agent?

No. It is a research prototype from the DeepSeek Harness team, built around one repository and event-driven sessions, and not an official DeepSeek product. dsh-leader-agent is a third-party plugin for a different job: one person running many features at once on a delivery board.

Super-agent vs. leader/worker orchestration

Super-agent keeps a long-lived agent that reacts to repository events and spawns isolated sessions. dsh-leader-agent keeps a Leader you talk to: it splits work into cards, dispatches persistent workers, and reports on a delivery board. If your unit of work is one repository with many events, use the prototype; if it is ten features and one person, use the board.

Can I run both?

Yes, in separate profiles — that is the supported setup. The prototype's SETUP keeps it in its own superagent profile, apart from the operator's, and this plugin runs in the web profile. Running both in one profile is not tested and not recommended.

Where is DeepSeek's Super-agent prototype?

At deepseek-ai/dsh-superagent-prototype (MIT). It is a research prototype, not an official DeepSeek product. This page is not affiliated with it.

Get Started

Install in seconds

Install on DeepSeek Harness Web or Desktop. The delivery board lives in the Web profile.

dsh >=0.2.1-rc.2 <0.3.0

Profile must be named web. Install the bundle and launch DeepSeek Harness Web:

# install the plugin, then start the web app $ dsh plugin --profile web add dsh-leader-agent $ dsh web

Install directly inside DeepSeek Harness Desktop without touching the terminal:

STEP 01 Open Plugins

Click Plugins in the left sidebar of DeepSeek Harness Desktop.

STEP 02 Add Plugin

Click Add plugin in the top right and enter dsh-leader-agent.

STEP 03 Install & Go

Click Install to add the plugin to Desktop.

Quit DeepSeek Harness Desktop completely first, then run the CLI bundled with the app:

# macOS; on Windows / Linux use runtime/cli/bin/dsh inside the install dir $ "/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \ plugin --profile desktop add dsh-leader-agent
