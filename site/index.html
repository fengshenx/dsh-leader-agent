One Leader drives the work and the review,
so you can run ten features in parallel instead of babysitting each one.

A leader/worker orchestration bundle for DeepSeek Harness (dsh). You state the goal once; the Leader splits work, dispatches workers, tracks every task to completion, checks what comes back and organizes review.

View on GitHub Install

What you get

One Leader drives dev and review

The Leader opens cards, dispatches workers, watches each one finish, verifies the deliverable and organizes review. Your attention goes back to what you want.

A board you can read at a glance

One board per project. Each card carries its executor slot and a live status light; click a slot to drill into that agent's session and keep talking.

Behavior lives in two files

LEADER.md holds the orchestration rules, SLOTS.md gives each worker role its own rules. Editing a file changes behavior — no session restart.

Many projects, one Leader each

The project tree lists the workers each Leader spawned. Swap in a new Leader and the existing workers plus undelivered reports move over.

Read back what a worker did

read_worker_session reads a worker's session log directly — every turn, every tool call, why anything failed — without waking it or triggering a model call.

Quiet workers get flagged

When a dispatched turn produces no report for 15 minutes, a patrol notice arrives with the session id, its card and a copy-pasteable read-back call.

Watch it run

One person, one agent team

  • You talk to the Leader only. Splitting, dispatching, tracking and acceptance all happen without you herding agents.
  • Workers are persistent sessions. Each owns one worktree, settles its own card when a turn ends, and reports back automatically.
  • Facts land on the board. Goal, scope, acceptance, links and live status — visible the moment you look.
  • You can always reach in. Drill into any worker's session directly, or read its log without waking it.

Install

Web

Profile must be named web; requires dsh >=0.2.1-rc.2 <0.3.0.

# install the plugin, then start the web app dsh plugin --profile web add dsh-leader-agent dsh web

Desktop (DeepSeek Harness Desktop)

GUI: Plugins → Add plugin → type dsh-leader-agent. Or use the CLI bundled with the desktop install (quit the app first):

# macOS; on Windows / Linux use runtime/cli/bin/dsh inside the install dir "/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \ plugin --profile desktop add dsh-leader-agent
