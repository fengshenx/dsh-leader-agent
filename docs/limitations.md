# 已知限制

本文只记限制：本 bundle 做不到什么、代价是什么。为什么做不到见 [capability-gaps.md](capability-gaps.md)，实现见[架构](architecture.md)，决策推演在 [Agent Notes](../.agents/notes/)。

## 宿主语义与运行形态

- **后台编排只适用于长驻组合**（web / desktop / sdk）。headless 是一次性 CLI，turn 结束会话即销毁，没有载体接收回报。
- **回报可能迟一轮**：按回合归属，用户下钻的回合不回报；Leader 的消息要等它被取走的那一轮。
- **回报依赖轮次正常结束**：结算点在 `turn/end`，worker 跑完前进程被杀，那一轮不结算，重启后只能打开会话看。
- **续聊消息在 worker 当前 step 结束才进上下文**：卡在长工具调用里时不会立刻看到；本插件没有中止手段。
- **会话被别的进程持有时不能冷恢复**：写句柄在另一个 dsh 进程手里，只能先关掉占用它的窗口。
- **不能新增 session event 类型**：仓外事件必须带 `ignorable` 且不进读路径，卡片与通知状态只能自己落盘。
- **项目手册没有 watcher**：改动在下一个模型请求生效；项目索引重建完成前的那一轮不注入。
- **历史消息不追溯**：改造前的通知按老形态渲染，改名前的任务消息退回官方上下文行。
- **worker 回报不进会话标题、turn 摘要与 Markdown 导出**：宿主只把 `source.kind === 'user'` 当真人输入。
- **回报要等父会话空闲才送达**：否则会混进输入框上方的消息队列，代价是 Leader 正忙时多等一轮。
- **自动续行上限可调，积压不可见**：设置页只有上限，撞上限的回报留在队列；调高释放、调低不释放。计数在内存，重启归零。
- **调高释放有并发窗口**：投递期间保存设置可能漏释放这些条目，直到下一次调高或人工开口。
- **看板模式切换可能滞后**：多窗口之间不实时同步，旧选择不迁移。
- **worker 头像只有五种形状**（round / organic / boxy / droplet / hexagon），颜色只取两档。
- **桌面脚本对 `DSH_HOME` 比 CLI 多一次 trim**：带首尾空格的取值在桌面侧与 CLI 侧路径不同。

## worker 的控制面

- **Leader 能纠偏、不能中止**：`message_worker` 只能把消息插进当前轮次的下一步；宿主的 `Agent.cancel` 没接成工具。
- **宿主的 `list_agents` / `send_message` / `interrupt_agent` / `wait_agent` 对 worker 无效**：worker 是根会话，不在 subagent 体系里，`interrupt_agent` 还会返回假成功。
- **权限与模型是派工时的快照**：之后改 preset、`SLOTS.md` 或 Leader 模型都不影响已派出的 worker。后台 `ask` 没人应答，需要审批的调用会被拒。
- **用户 claim 失败的在飞记录不会自动过期**：会留到任务进入下一轮或进程重启，期间 15 分钟巡查反复提醒。
- **`read_worker_session` 是视图，不是导出**：单条 4000 码元、单页 12000 码元，超出标注原长并给 `offset`；工具参数与成功结果不返回。
- **`list_workers` 只覆盖你派出的未归档 worker**：跨项目、别的 Leader 与已归档的看不到；「在跑」只算你派出的轮次，人下钻聊的那一轮不算（机制见[笔记](../.agents/notes/implemented/feature/2026-11-25-list-workers-tool.md)）。
- **无回报巡查有延迟**：60 秒扫一次、超过 15 分钟才提醒；重启后不补，人下钻的回合不计时。

## 看板与卡片

- **看板只在项目会话里出现**：项目目录里的普通会话与退役 Leader 只看到提示；换 Leader 后旧会话在面板复核后也不再展示卡片。
- **「看板」入口画不出来时留在 More 菜单**：宿主没有按会话过滤的扩展点，「开始」页仍会列出。
- **普通会话与退役 Leader 不能写卡**：工具可能还在列表里，调用时按当前身份被拒。
- **存量卡片不迁移**：旧记录没有创建会话 id，不出现在任何项目看板，只能 `list_cards({ scope: 'all' })` 看到。
- **非 `active` 卡不能绑槽位**；同一次调用里「关掉卡 + 绑定」也拒绝。
- **卡片编号全局递增**：按项目过滤会有空洞，归档与删除都不回收。
- **卡片详情的人工写操作只有链接与删除**：完成、重开、换执行者归 Leader 的工具；归档卡没有详情与删除入口，界面上清不掉。
- **卡片详情是打开瞬间的快照**：Leader 随后改卡不会刷新，要关掉重开。
- **卡面不显示所属项目**：看板已按项目过滤。
- **「等你输入」档没有数据源**：宿主的待处理交互机制在，但没有域发布它。
- **worker 回报气泡的折叠没有布局单测**：出现「展示更多」与否只能在浏览器里量。
- **归档入口只在有 hover 的设备上出现**：触屏上没有。

## 项目树与工作区

- **模型没有项目注册表工具**：加、列、换 Leader、删项目都只能人在左栏做；没有 web 导航服务时无法建项目，web 宿主上 native 选择器被拒时退回应用内目录浏览（[机制](../.agents/notes/implemented/bug-fix/2026-11-26-browse-directory-picker-fallback.md)）。
- **初始化提示的拒绝只在本会话生效**：换新会话会再问一次；想持久停用就创建 `LEADER.md`。
- **项目树是自建的，与官方工作区树并存**：worker 按登记表加目录 realpath 判定，退役 Leader 按项目记录判定。
- **项目会话不出现在官方工作区树是渲染层排除**：数据仍在，官方计数与搜索仍包含它们。
- **子目录里的 worker 不算项目下的 worker**。
- **项目不归属 dsh 工作区**：旧版本挂过的在启动时一次性摘掉。
- **「未分组」组头在组里只剩被排除行时一起藏起来**；判据宁可多显示。
- **项目目录临时不可用时会出现重复行**：左栏每 5 秒重读一次项目列表兜底。
- **同一个目录可能同时出现在项目区块与工作区树里**：那行属于用户，插件不动。
- **项目区块靠 DOM 注入取位**：宿主结构再变时内容退回原槽。
- **会话折叠只认当前会话**：运行中与完成未读不抬，绿点可能折起；只有当前会话保证可见，没有「等你输入」数据源。
- **撤销 Leader 会话只能停活动，不能删日志**：宿主没有删除会话的公开 API。

## 客户端与宿主耦合

- **客户端依赖宿主冻结模块表 `PLATFORM_MODULES`**：没有跨版本承诺，宿主移出条目后客户端半边整个起不来。
- **复用宿主 `MarkdownText` 与 `StateDot`**：宿主改签名或样式要同步；`StateDot` 的运行中只有灰圈。
- **Leader 会话形态依赖宿主的会话视图服务**：缺失时退回官方欢迎页。
- **图标数据与宿主 `ui-primitives` 耦合**：宿主改图标时本仓要同步。
- **会话标签栏靠 DOM 注入主面板**：宿主改结构时可能不显示或落位错误，会话本身不受影响。
- **隐藏「已编辑 N 个文件」靠渲染层**：宿主改类名或标记时卡片会重新出现。
- **看板保留 body 时会占住会话**：`keepMounted` 是圆点状态的来源，切走后仍 retain。
- **工具面裁剪靠 `tools.restrict()`**：项目索引重建完成前不裁。
- **浏览器侧 → 宿主侧走 Typert 远程通道**：手写的协议形状与宿主版本耦合。

## 发布

- **发布不可撤回**：同版本不能重发或删除，只能 `deprecated`；门禁全在上传之前。
- **provenance 只在 CI 生成**：本地 `npm publish` 没有 OIDC 身份。
- **包名与数据目录改名不迁移**：装过旧包的先 `dsh plugin remove`，旧卡片与登记不读。
- **git 直装没有客户端产物**：`lib/client.js` 不入库。
- **`verify:pack` 验的是磁盘上已有的 `lib/client.js`**：单跑前先构建。
- **装机 smoke 只覆盖宿主侧**：客户端只验产物形状。
