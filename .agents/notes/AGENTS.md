# AGENTS.md — Agent Notes

本目录是决策记忆：记**为什么这样定**、放弃了什么、怎么验证。格式与双轴口径见 [README.md](README.md)，何时写笔记见根 [AGENTS.md](../AGENTS.md) 的「提交与 PR」。

**每篇新笔记先做取代检查。** 动笔前检索活跃树里覆盖同一决策、机制或备选的笔记，逐篇定级：

- 已有主人 → 改那一篇，不新增重复记录；
- 整篇被取代 → 同一个 PR 里删掉；只有仍值得留存的历史决策才按 README 移入 `archived/`；
- 部分被取代 → 留在原 lifecycle，在被推翻的节前加 `> **已被 [标题](…) 取代**：…`，写明取代者与仍然成立的部分，两篇互链。

**`implemented/` 对代码现状负责。** 路径、符号、默认值、机制变了就同 PR 改事实；决策被推翻要新开一篇并链接旧篇，不能把旧篇改写成相反结论。

**不写流水账。** 笔记是决策记录，不是实现说明或验收日志。一篇只留四样：

- **背景**：为什么需要这个决定，最多一段；
- **决策**：定下的规则、判据与不变量，用现在时；
- **边界**：放弃了什么、代价与不覆盖的范围；
- **验证**：哪个用例文件钉住它，双向验证的关键读数一句话。

不写：文件清单（`**范围**`）、宿主源码行号与实现路径、CSS/数值细节、PR 编号与复审过程、逐条复现命令与读数表、测试总数。实现看代码，机制地图看 `docs/`，过程看 PR。多数笔记控制在 40 行以内；超出时先问「这条细节一年后还会改变一个决定吗」。

`archived/` 是冻结快照：只新增、不回改，也不作为当前行为的权威。
