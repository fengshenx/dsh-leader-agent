# Agent Note 的取代检查与一次全库体检

## 背景

`.agents/notes/` 的双轴口径与归档判据在 `README.md`，但「动笔前先做取代检查」「正文怎么算决策笔记」只散在根 `AGENTS.md` 的「提交与 PR」里，写笔记时常常想不起来。规模上来后，缺这一步的代价具体可见：笔记里有多组互相矛盾的现行事实，部分被推翻的决策仍以无指针的段落留着，还有从宿主抄来的 H1 前缀、漏网的 `Status:` 行与四套混用的验证/边界节名。

更主要的问题是正文写成了实现说明与验收日志：文件清单、宿主源码行号、CSS 数值、逐条复现读数、PR 复审过程占了大半篇幅，读完很难找到「到底定了什么」。97 篇合计 5,930 行。

## 决策

- **嵌套 `AGENTS.md` 的注入是刻意保留的**：宿主 `dsh-agent-instructions` 在 `read` / `write` / `edit` 命中笔记目录时，会把它作为 additional instructions 注入（当前安装的 `dsh 0.2.2-rc.2` 实测；`engines.dsh` 下限 `0.2.1-rc.2` 未逐版核对）。目的就是让写笔记的会话在上下文里直接看到检查清单，而不是靠记得去翻 README。代价是提示词面变大、且与 README 有重叠，所以**按「操作 vs 定义」分工**：`AGENTS.md` 只放动笔时的操作规则（取代检查三步、`implemented/` 同 PR 对齐现状、四节结构、不写 `Status:`、40 行上限），双轴取值、类目口径、归档与删除判据的完整定义留在 `README.md`，`AGENTS.md` 只留一句「细则见 README」+ 链接。
- **删除与归档的判据只归 README**：整篇被取代且有历史价值的移入 `archived/{class}/`（冻结、不回改）；只描述小范围 UI 调整或纯机械改动的直接删；被否决的提案移入 `rejected/` 并写明理由；删除或归档都在同一 PR 修好入链。`AGENTS.md` 的取代检查只写「整篇被取代 → 删；仍值得留存的历史决策按 README 归档」，不重复判据。
- **全库体检：先合并/删除，再补指针，最后按决策笔记重写**：整篇被取代的删除（独有理由已并入现主人）；仍成立的旧篇加部分取代指针或删失效段；删掉复现过程、平台差异表与 PR 复审清单这类流水账；节名统一为 `背景` / `决策` / `边界` / `验证`。然后按「决策笔记」标准重写全部 93 篇——背景一段、验证 1–3 行、多数 ≤ 40 行，实现细节、数值、行号、复现过程、测试计数不写；操作清单写进 `AGENTS.md`。总量 5,930 → 2,641 行。
- **格式门禁补 `Status:` 这一漏**：此前只匹配行首 `**状态**`，所以 README 说「不要写」而门禁不拦，漂移就是这么长出来的。补成正则同时匹配两种写法，用例加正反两向：宿主式 `Status: implemented` 报违规，正文行内出现不误伤。

## 边界

- 没有建 `archived/` 或 `rejected/`：本轮删除的要么是正在误导现行行为的过期决策，要么其独有理由已并入现主人，没有需要冻结的历史快照；宿主那套 hash manifest 不在本仓规模内。
- 历史笔记保留「协调者」叙述：术语统一笔记明确豁免 `.agents/notes/`，只同步已改到的现行代码引用。
- 只删明确的过期与流水账：小范围 UI 笔记若仍记录判据或用户可见行为，不因篇幅短而删。
- 压缩以保留决策为界：实现读数与过程被删，判据、代价与失效条件保留；不确定的细节优先留一句而不是整段。
- 取代检查仍是人的判断：门禁只查结构、节名与链接可达，查不出「这段事实已被推翻但没写指针」。
- **注入面是宿主版本耦合，且与 README 的边界靠人工维持**：当前 `0.2.2-rc.2` 上确认注入，下限 `0.2.1-rc.2` 未逐版核对；宿主改 `dsh-agent-instructions` 的匹配范围时，这份清单的可见性跟着变（不影响门禁）。门禁判不出一句话该归哪份文档，出现新事实时先问「是操作步骤还是定义」再落笔。

## 验证

`npm run check` 全绿：93 篇格式合规、1121 用例通过、15 篇 standing docs 在预算内；笔记总量 2,641 行。撤掉 `Status:` 分支即用例变红、还原后全绿。删除文件后链接门禁当场报出全部断链，逐处改指现主人后归零；删除前 grep 确认相关机制已不在代码里。注入面实测：本会话读写 `.agents/notes/` 时，宿主的 additional instructions 里出现了这份 `AGENTS.md`（`dsh 0.2.2-rc.2`）。压缩是人工重写，没有机械门禁能判「决策是否还在」。
