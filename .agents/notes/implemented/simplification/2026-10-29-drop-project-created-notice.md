# 建项目成功不再弹提示

## 背景

新建项目后左栏「项目」区块底部会多出一行「已建项目「…」。」，挤在项目行与「Workspaces」之间，看起来像残留或错误提示；它其实是建项成功后的回执，与失败提示共用同一个位置。

## 决策

**建项成功不弹提示，新项目行本身就是回执**：左栏「项目」区块的两个入口（点「加项目」选完目录、目录名当不了项目名时的改名框确认）都删掉 `setNotice(...)`，只为这条提示存在的 `createdName()` 一并删除——实际名字从此只在项目行上体现。

**回执的前提是行看得见**：项目行只在列表展开时渲染，而「加项目」按钮在 header 里、收起状态照样可点，所以两个入口在 `refresh()` 之后都补 `setListExpanded(true)`。不退回「收起时补一条成功提示」：提示位与失败提示共用容器，正是这次要删掉的混淆。

## 边界

- 失败提示全部保留（`建项目失败：…`、目录选择器不可用、改名框里的失败）。
- 空态提示保留：没有项目行可看时，它是唯一的出路说明。
- 「已从 dsh 移除项目…」等其他成功提示不在范围：它们对应「行消失了」这种反向变化，提示补的是消失后的确认。
- 建项后收起状态失去意义，会被自动展开；折叠与否仍由用户点的标题决定。

## 验证

无单测（客户端渲染），真机读数：建项后 `.dsh-leader-agent-project-notice` 不存在、项目行出现且 `aria-expanded` 为 `true`；对照是撤掉 `setListExpanded(true)` 后界面毫无变化、用户会再点一次而多建一个 `-2`，恢复后新行当场出现。
