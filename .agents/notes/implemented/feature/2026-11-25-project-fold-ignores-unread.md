# Agent Note: 项目树的会话折叠只认当前会话

Status: implemented

## Problem

项目树会话列表按注意力水位折叠：运行中、完成未读与当前会话都会把基线抬到它所在的位置。worker 常驻且频繁跑完，绿点几乎一直亮着，列表常被顶到十几条，「默认 5 条」形同虚设。需求是项目树的列表固定一页，未读不再撑开。

## Decision

`requiredWatermark` 只认当前会话：它仍在可见范围（前 50 条）内，刚点开的行不会当场消失；运行中与完成未读不参与水位。分页与收起项目后的水位重置不变（[收起项目回到默认一页](2026-11-24-project-fold-reset-on-collapse.md)）。绿点保留状态语义，折在「展开其余」后面。

这是刻意与宿主分叉：宿主的水位按运行中、未读完成、有子代理在跑、等你输入抬高。看板「已完成」区没有注意力档，不受影响。

## Alternatives considered

- **照宿主保留现状**：未读与运行中都抬水位，列表随 worker 活动膨胀；需求明确否掉。
- **只忽略未读、运行中照抬**：跑着的 worker 排在 5 条之后时仍会撑开列表；用户选的是严格一页。
- **逐条钉住未读行**：列表不连续，条数仍随未读增长，与固定一页相反。
- **按项目加开关**：多一层 UI 与落盘，只为一个项目的偏好；需求是项目树统一口径。

## Consequences

- 跑完未读或正在跑、但排在 5 条之后的 worker 要展开才看得到；项目收起时行首加载圈仍提示有 worker 在跑。
- 当前会话仍保证可见（前 50 条内），不会点开就消失。
- 从标签栏直接打开第 51 条及以后的会话时，它的行仍会被折起。
- 收益：项目树恒为一页，worker 多的项目不再因绿点或运行中膨胀。
