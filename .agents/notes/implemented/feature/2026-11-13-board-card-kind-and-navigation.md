# Agent Note: 卡面按导航目标组织轻量入口，并支持分类

Status: implemented

## Problem

卡面头部原来的「信号灯 + 编号 + 标题 + 停滞时长」把可读的标题挤在四件东西之间，链接胶囊与会话芯片又是两套容器，真正可点的入口反而最不显眼；同次还要补上任务分类（`kind`），它是任务流的短标签，本仓此前没有这个字段。参考实现用 Tailwind 与 Electron 自有主题，本仓只能用宿主 `--dsw-*` 语义令牌，所以「交互与信息层级照搬、材质与令牌走宿主」。

## Decision

- **头部只放只读身份与主信号**：左侧 `#编号 / 分类`，右侧信号灯；标题独占一行，与链接、会话共用卡面左缘。分类是纯文本，不加填充块、圆角或图标——填充块会被读成按钮，而分类点不动；分类与编号同用 caption 档，`/` 只做语义分隔。
- **链接去壳、静息态降权**：删掉发丝线圆角壳、前置图标与缩进。静息态只留次要文字的纯文本（400 字重），hover 与键盘焦点才提亮到链接色并出点状下划线——静息态是可读文本，交互态才是可点示能；下划线偏移取宿主规范的 3px，收起态链接行给容器补 1px 下内边距承接下划线。链接类型识别只留在详情浮层：标签与目标类型都可自由定义，卡面不需要这项猜测。
- **「+N」就地展开/收起**：旧实现点「+N」打开详情，入口位置（链接行）与导航目标（整卡详情）不一致，用户也无法在上下文里比较剩余链接；展开态换行、不再测量，`aria-expanded` 标出开关状态，收起后回到按实测宽度排布。
- **会话入口全部直出**：每项只有状态点、角色名与 hover / 焦点时出现的方向箭头，自然换行，不收进「+N」——角色数会增长，等宽按钮矩阵在窄栏里会变成按钮墙；只渲染已绑定会话的角色，没有会话可打开的角色不占位，未派工由信号灯的「无信号 / 未派工」承担。
- **停滞只由空心灯表达**：删除「停滞 Xd」文案；`attention` 混合态仍保留红实心（失败比停着更该先看），其余档位的停滞把实心换成 1px 状态色描边，形状变化只换填充、色相不动；与 `unknown` / `none` 的虚线区别在于停滞是确定的空闲，不是不可知。代价是卡面不再给出「停了多久」。
- **分类进数据模型但不进排序**：`kind` 可选、最长 24 字符、不能换行；`update_card` 传空串清除，建卡时空串与省略同义。判据只有一条——非空字符串才显示，非字符串与纯空白都按未分类（`cardKind`，卡面与详情浮层共用）。worker 不能改分类，那是 leader 对任务流的归类，与规格、标题同档；`list_cards` 每张卡显式列出分类（没有时写「无」），否则模型会把「未渲染」读成「工具不给分类」。

## Alternatives considered

- **分类做成填充块 / 胶囊**：会被读成按钮，但分类点不动；纯文本 + `/` 分隔。
- **保留链接的发丝线壳、前置图标与缩进**：静息态太抢眼、入口反而不显眼；去壳降权，hover/焦点才出链接色与下划线。
- **点「+N」继续打开详情**：入口在链接行、目标在整卡，位置不一致；改为就地展开/收起。
- **把会话入口也收进「+N」**：角色数会增长，等宽按钮矩阵在窄栏里会变成按钮墙；全部直出、自然换行。
- **保留「停滞 Xd」文案**：卡面要轻，停滞只由空心灯表达；代价是不再给时长。
- **把分类加进排序/过滤**：本次只做展示与写入通道，筛卡属于独立议题。

## Consequences

- **分类不参与排序、过滤或看板分组**：本次只做卡面展示与写入通道；要按分类筛卡得改用 `list_cards` 的查询参数，属于独立议题。
- **不复刻参考实现的卡面材质**：active 卡已用宿主行内卡片材质，done 卡仍是无材质的透明行——成品不抢注意力，材质差本身就是分组信号；宿主规则不允许中性 border 与 elevation 并存、也不允许功能样式表写主题选择器，深色可辨度交给主题令牌。
- **展开态与更多会话会让卡片变高**：这是保留上下文与全部会话状态的代价；默认收起态仍只占一行链接。
- **点「+N」不再打开详情**：无 URL 的引用链接仍打开详情（它没有别处可去），直接链接仍新窗口打开，整卡详情仍由点卡面提供。
- **存量卡没有分类**：不渲染「未分类」占位，也不做数据迁移。
- **两条操作左栏项目行的 e2e 场景并行跑会互相干扰**：必须按 `npm run e2e` 的串行车道跑。

收益：卡面把可点的入口放到最显眼的位置，分类与信号灯只做身份，不再和标题抢注意力。
