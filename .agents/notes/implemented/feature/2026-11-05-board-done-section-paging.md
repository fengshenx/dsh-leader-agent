# 看板已完成区的分页与行字号

## 背景

已完成卡累积后，「已完成」一次渲染全部历史卡：历史区比进行中的卡片还长，滚动很久才到下一块交付物，每 2 秒轮询也会重建整棵列表；行标题比卡号更抢眼，历史浏览的视觉重量压过了进行中的卡。

## 决策

- **已完成区按 30 张一页折叠**，口径照宿主工作区树的会话折叠：默认露出一页，点「展开其余」再加一页，剩余不超过一页时一次放完（水位抬到 `Infinity`），展开到最后一页后按钮变「收起」，收起回落到基线；水位只升不降。水位是组件本地状态、不落存储——宿主也不持久化会话列表的展开状态。
- **页大小是 30，不是宿主的 5**：已完成卡是历史浏览，30 张一页比会话列表的 5 条更省点击；两边共用同一套折叠口径，页大小各自成常量。
- **折叠逻辑收口到 `session-watermark.js`，页大小参数化**：共享实现是 `foldRows(rows, watermark, { pageSize, baseline, noun })` 与 `nextRowWatermark(hiddenCount, visibleCount, pageSize)`，`foldSessions` / `foldDoneCards` 只负责各自的基线与量词；第二参统一收「当前可见数」，不再一边叫水位、一边叫可见数。
- **翻页判定抽成纯函数**（共享层实现，两端的 `foldDoneCards` / `nextDoneWatermark` 是薄封装）：组件不可单测，「剩余不超过一页是否一次放完」「展开完是否变收起」这类边界要能直接断言，所以不进 JSX。
- **已完成行标题降到与卡号同字号**：完成区行内四段（勾选图标 / 卡号 / 标题 / 完成时长）同一档位，大字号只留给 active 卡标题。

## 边界

- **水位不持久化**：面板重挂载（切会话、切 tab）后回到一页。
- **没有注意力抬升**：宿主会为运行中、等你输入的会话抬高水位；已完成卡没有对应状态，只有分页。
- **收起只回基线**：不回到上一次展开的页码。
- **按钮文案说「卡片」不说「会话」**：看板里「会话」另有所指（槽位 chip 打开的才是会话），沿用宿主会话列表的文案会指错对象。

## 验证

`tests/board-projection.test.js`、`tests/session-watermark.test.js` 与 `tests/e2e/board-done-paging.e2e.js`。双向：把 `foldRows` 的 `expanded` 判定改回「只看是否超过一页」→ 两端断言红；把 `board.js` 的 `doneFold.rows.map` 改回 `done.map` → e2e「默认应渲染 30 行」红。还原后全绿。
