# Agent Note: 看板新增炫酷（线路图）与工作两种模式

Status: implemented

## Problem

看板原本只有一种纯列表：日常扫任务够用，但录屏、发社交媒体时看不出「leader 把活分给了谁、数据在往哪流」。用户要的「炫酷」不是换卡面材质，而是一张工作流图：卡片挂在主干上，执行者是支线，只有真实的数据流才亮金色光。

约束：宿主切到浅色主题时这块面板仍要保持深色；工作模式必须还是现在这套列表。

## Decision

- 两种模式，存 localStorage（默认炫酷）：显示偏好跟浏览器走，不写项目数据；同一运行时用模块级订阅即时生效，其它窗口靠 `storage` 事件同步。
- 线路图是「列表 + 垫在下面的 SVG」，卡片与入口的 DOM 语义不变；渲染后实测行位置，几何规划是纯函数，绘制单独一层。
- 线路图模式把执行者移到卡面右侧竖槽：支线要画在卡面外面，留在卡里会被盖住。工作模式保持原 DOM。
- 只有「执行中」画金色并跑光点，「需注意」画红，其余灰线；光点有上限，`prefers-reduced-motion` 下只留静态线。颜色取宿主与主题无关的 `--dsw-static-*` 标尺，深色面板不随主题变。
- 重画由「模式 + 卡片 id + 信号」签名触发，轮询换数组不会让光点重头跑；尺寸变化由 `ResizeObserver` 兜住。
- 设置入口用宿主的 `settings.section` 槽位；槽位不存在时静默缺席，看板按默认模式走。

## Alternatives considered

- **深色玻璃 / 任务控制台换皮**：用户明确否掉，要的是节点与连线，不是另一种卡面材质。
- **星型 / 流式布局**：都做进模拟稿比较过，420px 面板里星型挤成一团、流式看不出归属，用户选线路图。
- **浅色主题配浅色线路图**：纸感 / 蓝图 / 石墨三套浅色都被否，要求任何主题下保持深色面板。
- **执行者留在卡内、只画断头线**：支线会被卡面盖住，是假连线，违背「线表示归属」。
- **模式存进项目数据或宿主设置文档**：跨设备一致对这个显示偏好不成立，还要加异步取数与 RPC。
- **CSS `offset-path` 替代 SMIL**：同一条路径要复用给 trail 与 comet，收益只是少一个元素。

## Consequences

- 线路图模式每个卡片行多一层包裹，执行者从卡内移到右侧竖槽，键盘顺序不变（卡面 → 执行者）。
- 深色面板只作用于看板列表，详情浮层 portal 到 body，不受影响。
- 模式按浏览器保存，换浏览器、换机器不跟随；设置页写明这一点。
- 没上 e2e：原有看板场景在本机起不来（项目行不渲染），且 e2e 只做逻辑检查；GUI 表现未实测。
- 使用手册补了模式说明；`docs/usage.md` 原本就贴线，按门禁把天花板从 7402 抬到 7524，没有删原有内容。
- 收益：同一块看板在演示时能一眼看出派工拓扑，日常仍可切回零动效的列表。

## Testing

- 单测钉住模式规范化、读写失败、订阅广播，以及信号到线语义与 tick / 支线路径；样式门禁的白名单逐条对 `dsh-client-ui-theme@0.2.1-rc.2` 的产物核过。
