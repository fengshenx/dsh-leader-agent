# Agent Note: 会话切换不再重建线路图

Status: implemented

## Problem

宿主的右栏按会话隔离（`RightbarRoot` 保留每个会话的子树），非当前会话用 `display:none` 隐藏。看板 body 有 `keepMounted`，切走不卸载——但线路图是命令式 SVG：`ResizeObserver` 看到 stage 从 0 变回 N，就调 `drawRail` 清空并重建整层，SMIL 光点随节点一起重建，动画从头起跑。于是每次切换会话（哪怕右栏面板本身没换、宽度没变）都会看到光点跳回起点、顿一下。

宿主只负责显隐，重画是看板自己的；真正需要重画的只有「宽度变化」或「内容/状态签名变化」。

## Decision

- `drawRail` 前先判：stage 尺寸为 0（隐藏）直接跳过；宽度与 `railKey`/主题/减弱动效签名都没变时跳过。隐藏期间的 0 尺寸不再清空 SVG，显示时尺寸恢复、签名相同就保留原来那层（含动画节点）。
- `ResizeObserver` 的回调改成 80ms 尾防抖：面板过渡/拖拽期间尺寸连续变化时只画最后一次，不再每帧重建。
- 签名只带 `clientWidth`（宽度决定换行与行高），不带高度：高度变化不影响线路几何，滚动也不该触发重画。
- 首次打开一个收起的右栏、或真实改变宽度时仍会重画一次；那是几何真的变了，接受一次重建，不在本次范围内做跨重建的动画相位延续。

## Alternatives considered

- **保留动画相位（负 `begin`/`animation-delay`）**：能让必要的重建也从当前相位接上，但 SMIL 在节点后插入时是按文档时间还是插入时间采样，浏览器行为没有把握；先解决「本来不用重画却重画」，相位延续等确有需要再做。
- **改宿主用 `visibility`/`transform` 隐藏会话**：那在宿主仓库，且会影响主面板布局与无障碍；插件不能改。
- **把看板 DOM 跨会话搬过去**：宿主没有跨会话 pin 面板的公开入口，看板是每会话一份 tab body。
- **只在 `railKey` 变化时重画、完全去掉尺寸监听**：右栏宽度变化（拖拽、窗口缩放）会让线路错位。

## Consequences

- 会话来回切时线路图节点不重建，光点连续跑；切到第一次打开且右栏收起的 worker 仍有宿主自己的面板滑入。
- 拖拽右栏宽度时线路图延迟 80ms 再对齐，期间可能短暂错位；比每帧重建、动画反复起跑好。
- 隐藏期间卡片轮询本来已暂停，签名不会变；显示后若槽位状态真的变了，`railKey` 变化仍会重画一次。

收益：会话来回切时线路图节点不重建、光点连续，不再每次切换都从头上路。

## Testing

- `npm run check` 与 `npm run build:client` 通过；`board-rail.js` 是登记的单测不可加载文件（依赖 DOM 实测与 SMIL），本次行为靠真机切换观察。
- 复核点：开着看板在 leader 与已打开过看板的 worker 之间来回切，线路图的光点应连续；首次打开一个收起的 worker 右栏仍会看到宿主的面板滑入。
