# 换新 Leader 后的落点与官方折叠计数

## 背景

两处用户可见缺陷：

1. **换新 Leader 后新会话「闪一下就没」**。新 leader 会话建出来就挂进项目目录的工作区，
   官方工作区树立刻渲染出那一行；而它属于排除集（现任 leader 不在官方树里重复出现），
   渲染层要等项目摘要刷新后才知道新 id，那一拍就是用户看到的闪烁。项目区块那一行又
   没有肉眼可见的变化（名字没变、当前 leader 不在项目树下单独出行），于是新会话看起来
   凭空消失。
2. **官方「展开其余 N 个会话」的 N 含被隐藏的项目会话**。折叠按数据层算，排除了渲染
   行却不排除计数：同一个目录既是工作区又是项目时，数字比实际能露出来的行多；全部
   会话都被排除时，会留下一颗点了没反应的按钮。

## 决策

### 换新 Leader 先写回摘要、再打开新会话

`replaceLeader` 的远程响应带回新 `leaderSessionId`：先 `setProjects` 把它写进本地摘要
（新 id 立刻进排除集，不必等 `refresh` 回来），再用 `uiWorkspace.openSession` 打开它。
打开是这件事唯一的回执——新 leader 不在项目树下单独出行，官方树里又被排除，不导航
过去用户只能靠猜。

### 折叠数字在渲染层按分组修正

同一个渲染层（`workspace-exclusion.js`）在标完会话行之后处理展开按钮：

```
真实剩余 = 宿主口径 N − (该组排除集大小 − 该组已渲染且隐藏的行数)
```

- 该组排除集大小由 `excludedSessionCountsByWorkspace` 从工作区快照（`sessionIds`）与
  归档集合算出；归档的会话宿主自己不渲染，不计入。
- 已渲染隐藏行按「向上第一个带展开按钮的祖先」归组：官方把会话行与按钮都包在
  `HoverCard` 的 `span` 里，分组容器的直接子元素不是会话行；子工作区的行不能算到父组。
- 真实剩余为 0 时给按钮加隐藏类，避免点开也看不到东西。
- 改写后把宿主原文案记在 `data-expand-origin` / `data-expand-written`：React 直接改
  文本节点时不会碰 `data-*`，靠「当前文本是否等于我们写的那句」区分来源，否则会把
  改过的数字当宿主口径再减一次，数字一路往下掉。
- 观察器补 `characterData`：React 重写按钮文本走的是文本节点，不触发 childList。
- 卸载时把文案还原成宿主口径，插件重载而页面不刷新时不会留下少掉的数字。

### 文案统一为「换新 Leader」

按钮 title、菜单项、提示条、看板指路文案与文档里的界面引用一起改；代码注释里的
「换新 leader 会话」是动作描述，保持原样。

## 边界

- **点击步长改不了**：宿主每点一次展开加 5 条（最后一次放完），文案减的是真实剩余，
  所以一次点击新增的可见行可能少于文案的变化量。要彻底对齐需要宿主支持按外部集合
  过滤会话（见 capability-gaps 第 29 条）。
- 只修真实工作区分组；「未分组」桶里的项目会话（工作区被删、还没点过项目行的窗口期）
  不改按钮——那个桶没有 workspaceId 可对应。
- 闪烁只能缩短、不能根除：建会话到响应到达客户端这一段仍在宿主手里。

## 验证

- `tests/workspace-exclusion.test.js` 新增 9 条：剩余数扣减、全部排除时收起按钮、
  反复标记不重复相减、宿主重写后按新数字重算、无分组统计时不碰按钮、文案无数字时原样、
  剩余数相同不重写、按组统计排除集（归档不计）、子工作区的隐藏行不算进父组。
- 双向验证：注释掉 `adjustGroupOverflow` 调用，上述计数用例 5 条变红；还原后 22 条全绿。
- `npm run check`：1003 个用例通过，`workspace-exclusion.js` 行覆盖 79.83%（门槛抬到 79）。
- `npm run e2e`：真实宿主挂载冒烟（3 条场景全绿），页内无 console 错误。
- 真机验证（一次性脚本，seed 一个无 leader 的项目 → 点「换新 Leader」）：
  1. 项目行从「leader 不可用」恢复可打开；
  2. 新 leader 会话行出现在官方工作区树并带上排除类；
  3. 主区域切到新 leader 会话（composer 可编辑）；
  4. 往真实分组容器注入一条与宿主同形的 `data-row-key="overflow:<id>"` 按钮，
     已渲染隐藏行数与排除集相等时文案保持「展开其余 3 个会话」；
  5. 把那条隐藏行移出 DOM（模拟未渲染），观察器把文案改成「展开其余 2 个会话」。
