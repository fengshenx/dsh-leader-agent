# 宣传片验收

验收不是“看起来还行”，而是逐项能指出读数或帧。先看硬指标，再看审美。

## 成片

- [ ] `ffprobe`：视频/音频时长一致；分辨率、fps、codec 符合平台。
- [ ] 第一帧不是加载器、白屏或黑屏；第一句旁白出现时画面已经可读。
- [ ] 最后一帧停在品牌/行动点，不是淡成黑屏。
- [ ] 抽帧检查所有场景切换点：无重复场景、无空场景、无跳帧造成的错位。
- [ ] 没有录进鼠标、hover 高亮、滚动条、浏览器边框或调试 HUD。
- [ ] 字幕与旁白一致；没有压住关键文字；没有长期挡脸/挡卡片。

抽帧建议：

```sh
for t in 1 5 12 20 28 33 36 42 45 49 55 62; do
  ffmpeg -y -ss "$t" -i out.mp4 -frames:v 1 "frame-$t.png"
done
```

## 音频

- [ ] 有声音，不是静音轨；左右/单声道输出与平台兼容。
- [ ] 平均约 −17 dB、峰值低于 0 dB；没有削波。
- [ ] 每个场景第一句和画面动作同步；没有越到后面越偏。
- [ ] 段间没有 3 秒以上死区；也没有把两句话粘成一个词。
- [ ] 专有名词读法可接受；品牌名与画面一致。
- [ ] 没有把 API Key、原始路径、内部代号读进旁白。

## 竖屏与手机

- [ ] 1080×1920 下，正文/注释 ≥ 约 30px；等效到 390px 宽的手机 ≥ 约 11–13 CSS px。
- [ ] 390×844 实际截图检查一次，不只看桌面预览。
- [ ] 关键标题不被上下黑边裁切；安全区内没有平台按钮遮挡。
- [ ] 长标题不出现孤字/单字成行；必要时空格或换行重排。
- [ ] 截图卡片在手机上仍能读出标题、槽位、状态；读不出就放大或改成 HTML 大字。

## 素材与真实性

- [ ] 截图来自真实 UI；没有手绘假按钮、假数据、假运行结果。
- [ ] 数据多样：不同标题、不同状态、2–3 个槽位；不是十张一样的卡。
- [ ] token、真实用户目录、内部 URL、个人信息没有入镜。
- [ ] 封面里的卡片与成片里的产品状态一致，不出现“封面有、片中没有”的功能。

## 封面

- [ ] 25% 缩略图下主标题仍可读。
- [ ] 标题是“我的/分享我的 + 具体问题 + 方法/收益”，不是纯产品名。
- [ ] 9:16 与 3:4 各自排版，不是裁切。
- [ ] 图片全部加载；没有外网依赖；没有错别字。
- [ ] 封面主张与视频旁白、结尾品牌一致。

## 交付

- [ ] MP4、封面 9:16、封面 3:4、旁白 MP3、SRT、交互 HTML、可编辑 HTML 都在。
- [ ] 文件名带比例/用途，能一眼看出哪个文件发哪里。
- [ ] HTML 是静音预览还是带音频，交付说明里写清楚。
- [ ] `.dev` 下的临时录屏、截图、密钥、个人路径没有进入仓库。
- [ ] 如果给了两种以上版本，说明差异与推荐版本，不让用户自己猜。
