# 分镜

1080×1920，6 个场景、8 段旁白。时间是视频时间，不是音频文件内部时间。

| 场景 | 时间 | 旁白 | 画面 | 素材/实现 |
|---|---:|---|---|---|
| S1 现场 | 0–8.958 | 同时跑五个任务，是什么感觉…… | 五张任务卡纵向堆叠，消息从右侧不断插进来；最后标签变成“注意力被撕成五份”。 | HTML 卡片 + 真实任务文案 |
| S2 循环 | 8.958–18.796 | 问题不在任务量，而在人…… | “你”在竖环中心，四个节点绕着你转；说到“阻碍点”时环卡住。 | HTML + SVG 环 |
| S3 编排 | 18.796–27.246 | 把人，从循环里拿走…… | Leader 光球接管入口，20 张执行者卡片铺成网格，辐条逐个点亮。 | HTML + SVG |
| S4A 输入 | 27.246–34.164 | 把任务丢给 Leader…… | 真实 App 窗口出现，大号输入框逐字打出“把这20个任务并行推进，完成后统一向我汇报”，发送后右侧开始长卡。 | 真实截图 app-running + HTML 输入框 |
| S4B 卡片 | 34.164–42.954 | 右侧，长出一张卡…… | 看板面板出现，三张真实任务卡依次长出；标题、槽位、状态、2–3 个槽位清晰可读。 | 裁切卡片图 portrait-card-20/19/18-wide |
| S4C 汇报 | 42.954–49.806 | 不用再一个个追问…… | 你说的“向我汇报进度”气泡发出，汇报卡展开 12/6/2，下面出现 20/20 回执墙。 | HTML 汇报卡 + 回执网格 |
| S5 结果 | 49.806–59.096 | 效率，大幅提升…… | 三组数据竖排：1 个入口、20+ 并行任务、1 句话拿进度；底部一句“你只负责决定”。 | HTML |
| S6 尾声 | 59.096–66.914 | 一个人，管二十个并行任务…… | 品牌字标 + “一个人，管 20 个并行任务” + 安装命令；末帧停在品牌，不淡黑。 | HTML |

## 节奏

- 前 3 秒是“同时跑 5 个任务”的冲突，不铺垫行业背景。
- S2 的“人成了阻碍点”是全片转折，画面同步卡住，旁白不赶。
- S4 占 22.5 秒，是证明段：输入 → 卡片 → 汇报，每段都有可读的真实产品细节。
- S5 只做三组数字，不堆功能；S6 留 7.8 秒，品牌和安装命令都看清。

## 竖屏重排

- 横版 16:9 不直接加黑边；标题、卡片、数据都按 1080×1920 重新排。
- 桌面 App 截图只作为“真的在跑”的上下文；手机上要读的标题/槽位用裁切卡片与 HTML 大字。
- 舞台按 `min(innerWidth/1080, innerHeight/1920)` 缩放；手机 390×844 下正文等效 ≥13 CSS px。
